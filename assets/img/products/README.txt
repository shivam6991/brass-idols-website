Product photos go in this folder.

Name each file the same as the "images" entry in assets/js/data.js, e.g.
  ganesha-sitting-6-a.jpg
  ganesha-sitting-6-b.jpg

Guidelines
  - Square, around 1000 x 1000 px
  - Under 300 KB each (compress free at squoosh.app)
  - 2-3 angles per idol; extras show as thumbnails in the product window
  - Shoot against a plain light background so the brass reads warm

Until a file exists here, the site draws a placeholder automatically,
so the catalogue never shows a broken image.
